# Gemini Hindi script skills

Writer skills for the Gemini app that research and write Hindi YouTube episode scripts with the
channel owner, one skill per show. Each skill holds the show's voice and rules, how the owner and
Gemini work through research, outline, hook and script, and the fixed *intake package* the skill
writes on FINAL for a production pipeline to import word for word.

| Show | Skill |
|---|---|
| [`gaon_kahani`](gaon_kahani/SKILL.md) | `gaon-kahani-script` |
| [`parenting`](parenting/SKILL.md) | `bundle-of-cuddles-script` |
| [`pauranik_kahani`](pauranik_kahani/SKILL.md) | `pauranik-kathayein-script` |
| [`pravachan`](pravachan/SKILL.md) | `pravachan-writer` |

## Use

Make a Gem in the Gemini app and paste a `SKILL.md` as its instructions, or attach the file to a
chat and ask Gemini to follow it. Each file opens with "How the owner uses this skill".

## Source

These files are mirrored from a private production repo, where they are edited; this repo is
updated automatically on every change there. Changes made here are not carried back.
